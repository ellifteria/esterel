5 Rhombus Kernel Esterel Reference🔗ℹ

 import: esterel/kernel package: esterel-rhombus-lib

The esterel/kernel Rhombus library is built on the Racket esterel/kernel library.

5.1 Running Esterel Code🔗ℹ

expression

esterel:

  body

 

expression

esterel ~pre pre:

  body

Returns a value that, when passes to react, will evaluate the body in a context where in_esterel returns #true.

In the second form, the value of pre is expected to be a natural number. It is a limit on the history that’s saved for signals in previous instants. It defaults to 0.

function

fun react(r, ~emit: signals = [])

Runs one instant of r.

If signals are supplied, they are emitted at the start of the instant; valued signals must be paired with values.

The result has the values of the signals that were emitted. Additionally, if a signal is not a valued signal and the computation depends on it not being present (e.g., if it is pass to is_present), it is included in the resulting hash, mapped to #false.

If the code is not constructive, an exception is raised.

function

fun is_esterel(v)

Recognizes the result of esterel.

function

fun in_esterel()

Returns #true if called within the dynamic extent of an expression in a esterel form.

function

fun debug_when_must(stx)

Evaluates stx when the entire debug_when_must form must be executed. Raises an error if evaluated outside of an esterel form.

This can be used to debug Esterel in Racket programs. Sometimes, code inside esterel is run as part of an exploration to determine if signal might be emitted and, in that case, we do not know that that code must run. In such situations, effectful code (such as printf) can run multiple times, leading to confusing behavior. Wrapping such debugging IO operations in a debug_when_must form can help to understand an Esterel in Racket program.

function

fun signal_index(s)

Returns the index of signal s. This index counts the number of times the with_signal that introduced s has been executed to produce this particular signal. If s was created outside the dynamic extent of esterel, signal_index returns #false.

function

fun signal_combine(s)

Returns the combing operation for signal s or #false if s is not a valued signal.

function

fun is_present(s, ~pre: pre = 0)

When pre is 0, returns #true if s is present in the current instant.

If pre is larger than 0, returns whether or not s was present in the preth previous instant. If pre is larger than the value of pre passed to esterel, an error is raised.

function

fun signal_value(s, ~pre: n = 0, ~can: can = Set())

If n is 0, returns the value of s in the current instant, unless s hasn’t been emitted in the current instant. In that case, returns the value of s in the previous instant.

If n is larger than 0, returns the value of s in the nth previous instant. If n is larger than the value of pre passes to esterel, an error is raised. If the value has never been emitted and the signal’s declaration did not have an ~init clause, an error is raised.

The ~can argument indicates which signals can be emitted by the remaining computation and must be supplied if n is 0. That is, if it is possible that some signal can be emitted in the current instant after signal_value returns, then that signal must be in the set can.

function

fun emit(s)

 

function

fun emit(s, v)

Emits s. If one argument is passed, then s must not be a value-carrying signal.

If two arguments are passed, then s must be a value-carrying signal and the value v is emitted.

5.3 Control Operations🔗ℹ

expression

par

| body

| ...

Executes each body in parallel, waiting for all of them to complete. The result is a set of all of the values of the bodys.

expression

left ||| right

Equivalent to par | left | right.

Executes left and right in parallel, waiting for both to complete. The result is a set of the values of left and right.

expression

pause

Pauses the current thread. When all of the threads are paused (or canceled via exit_trap), the instant is over. During the next instant, control picks up wherever the pause was.

expression

suspend:

  body

  ~when when

When resuming from a pause within body, suspends body when when returns a #true value. In other words, if a pause is encountered when evaluating body, upon resuming body, suspend suspends body if when returns a #true value. This suspension also affects any with_signals within (the dynamic extent of) when.

expression

with_trap t:

  body

Binds t to a newly created trap and evaluates body. If the trap bound to t is passed to exit_trap, the computation in the rest of body is skipped and the result of with_trap is the value passed to exit_trap.

function

fun exit_trap(t)

Exits to the trap t. Does not return.

function

fun is_trap(v)

Recognizes values bound by with_trap.
