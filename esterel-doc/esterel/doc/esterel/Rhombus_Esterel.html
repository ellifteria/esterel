5 Rhombus Esterel🔗ℹ

 import: esterel/full package: esterel-rhombus-lib

The esterel/full Rhombus library is built on the Racket esterel/full library. As in the Racket esterel/full library, it provides all of the names documented here as well as the names documented in esterel/kernel.

expression

loop:

  body

  ...

  ~each restart

 

expression

loop:

  body

In the first form, runs body over and over. In the second form, starts by running body and then halting. Restarts body when restart becomes true.

expression

await when ...

 

expression

await when ... ~n n ...

 

expression

await ~immediate when ...

In the first form, pauses until when returns a true value, but at least one instant. In the second form, pause until when returns a true value ~n times. In the third form, the value of when is tested in the first instant, and thus the await might terminate immediately.

expression

every s ...:

  body

 

expression

every s ... ~n n ...:

  body

 

expression

every ~immediate s ...:

  body

In the first form, awaits s evaluating to a true value and then starts running the body; when whenever s becomes true, restarts body. The second form is similar to the first, except that it waits for s to be true n times before restarting body. In the third form, if s evaluates to a true value in the current instant, the body is evaluated in the current instant.

function

fun sustain(s)

 

function

fun sustain(s, v)

Emits s and pauses in every instant, forever.

As with emit, if s is a valued signal, two arguments must be supplied and if s is not a valued signal, two arguments may not be supplied.

function

fun halt()

Pauses in every instant, forever.

expression

abort:

  body ...

  ~when when ...

 

expression

abort ~weak:

  body ...

  ~when when ...

 

expression

abort ~weak:

  body ...

  ~when_immediate when ...

Terminates when body terminates or when when returns a true value. If ~weak is present, the bodys are executed when when is true; they are skipped if ~weak is not present. If ~when is used, the bodys are executed at least once and the abort runs for at least one instant; if ~when_immediate is used, the when is tested in the first instant and the expression terminates in the first instant if when returns a true value.
